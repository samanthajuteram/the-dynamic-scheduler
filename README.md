# the-dynamic-scheduler

If you are anything like me, goal setting and scheduling is the way you run your life. For me, I set fitness, reading, and study goals weekly. On many occasions, something comes up or simple fatigue has me missing the allotted time I set out for these goals, leaving me with the "I missed it, so the week is ruined" feeling.

This idea came to me in my Introduction to Artificial Intelligence class at UCI. We were covering Constraint Satisfaction Problems and how they can be used to find solutions when there are multiple variables, constraints, and possible outcomes. It got me thinking: what if I could apply this concept to my own weekly schedule?

Instead of treating a missed task as a failed goal, what if my schedule could adapt around it?

The goal of this project is to build a scheduling system that takes my weekly goals, available time, and personal constraints into account, then creates a schedule that can adjust when life gets in the way. If I miss a workout, fall behind on reading, or have an unexpected commitment, the scheduler should be able to reconsider the remaining week and find a feasible way to fit things back in.

The big idea is that **A schedule should work around your life, not the other way around**
